# Sattva Design Studio — Premium Responsive Website

A static, deployment-ready portfolio site for Sattva Design Studio. The visual direction takes cues from the supplied premium warm-product landing page reference: deep brown, warm copper/sand accents, oversized editorial typography, rounded image panels, floating cards and conversion-focused CTA treatment.

## Run locally
Open `index.html` directly or serve this folder with any static server.

## Deploy
Upload the contents of `sattva-studio-site/` to Vercel, Netlify, GitHub Pages, or any static hosting provider.

## Notes
- Current portfolio images use the image assets exposed by the supplied Sattva demo URL.
- Replace those image URLs with locally hosted project photography for a fully independent production deployment.
- WhatsApp CTA uses +91 82646 77777.
